# RecipeComposeApp

**RecipeComposeApp** — учебное Android-приложение с кулинарными рецептами, полностью разработанное на **Kotlin** с использованием **Jetpack Compose**.  
Проект создан для изучения современной Android-разработки, декларативного интерфейса, навигации, управления состоянием и разделения приложения на слои.

---

## 📱 Основные возможности

- Просмотр категорий блюд
- Отображение категорий в виде сетки
- Просмотр списка рецептов выбранной категории
- Детальный экран рецепта
- Отображение изображения и названия блюда
- Просмотр списка ингредиентов
- Пошаговая инструкция приготовления
- Пересчёт количества ингредиентов для выбранного числа порций
- Добавление рецепта в избранное
- Отдельный экран избранных рецептов
- Возможность поделиться ссылкой на рецепт
- Открытие рецепта с помощью Deep Link
- Состояния загрузки и отсутствия данных

Сейчас данные хранятся непосредственно в приложении с помощью временного репозитория-заглушки `RecipesRepositoryStub`.

## 🧩 Основные экраны

### Категории

Главный экран приложения со списком категорий блюд:

- бургеры;
- десерты;
- пицца;
- рыба;
- супы;
- салаты.

Категории отображаются в виде сетки с изображением, названием и кратким описанием.

### Рецепты

После выбора категории открывается список доступных рецептов с изображениями и названиями.

На текущем этапе рецепты добавлены для категорий **«Бургеры»** и **«Десерты»**.

### Детальный экран рецепта

На детальном экране отображаются:

- изображение и название блюда;
- список ингредиентов;
- количество порций;
- слайдер для изменения количества порций;
- автоматический пересчёт ингредиентов;
- пошаговая инструкция приготовления;
- кнопка добавления в избранное;
- кнопка для отправки ссылки на рецепт.

### Избранное

В приложении создан отдельный экран для избранных рецептов.

На текущем этапе состояние кнопки избранного сохраняется при изменении конфигурации экрана. Постоянное хранение и отображение добавленных рецептов на экране избранного находятся в разработке.

## 🧠 Структура проекта

Проект разделён на несколько основных частей:

- **`data`** — DTO-модели и репозиторий с тестовыми данными;
- **`ui`** — экраны, UI-модели и компоненты интерфейса;
- **`core`** — общие константы, тема, навигация и вспомогательные функции.

Для преобразования данных используются отдельные модели:

- `CategoryDto` → `CategoryUiModel`;
- `RecipeDto` → `RecipeUiModel`;
- `IngredientDto` → `IngredientUiModel`.
